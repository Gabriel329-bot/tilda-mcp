#  Tilda MCP Server

тказоустойчивый сервер по протоколу **Model Context Protocol (MCP)** для автономной генерации, стилизации и точечного редактирования коммерческих лендингов на платформе **Tilda**.

вижок спроектирован так, чтобы -агенты могли собирать законченные конверсионные страницы без ручной верстки, экономя токены и время сборки.

---

##  лючевые возможности

###  рхитектура One-Shot Orchestrator
* **	ilda_fast_generate_landing**: Сквозная сборка лендинга из 10 секций (Header, Hero, Features, Metrics, Pricing, Testimonials, FAQ, Form, Footer, CSS) за один вызов инструмента (~1012 сек).
* **инимум токенов**: з публичного MCP-реестра исключены низкоуровневые атомарные вызовы.  контекст LLM не передаются тяжелые логи и дампы HTML.
* **ыстрый батчинг**: араллельное обновление независимых блоков пакетами (Promise.all) без риска блокировки сессии Tilda.

###  Smart Defaults & Стилизация
* **отовые пресеты**: втоматическая настройка тем (dark, minimal, warm) без раздувания схем.
* **Hero Overlays**: лубокие контрастные оверлеи (75%/85%) для гарантированной читаемости типографики поверх любых фонов.
* **окализация форм**: втоматическая русификация полей, плейсхолдеров и маска номера  (+7).
* **Auto-CSS Glassmorphism (T123)**: золированная инъекция кастомных стилей с эффектом матового стекла (ackdrop-filter: blur(16px)), аккуратными границами и неоновыми акцентами для тарифов Хит продаж.

###  тказоустойчивость уровня Production
* **Session Healthcheck (checkAuth)**: роверка валидности куки до создания страницы. гновенное прерывание с понятной ошибкой при протухшей сессии ([AUTH_EXPIRED]).
* **Exponential Retry & Backoff**: втоматический повтор запросов (до 3 попыток с паузами 1000 мс и 2500 мс) при ошибках 429 (Rate Limit), 502, 503, 504 и сетевых сбоях.
* **Транзакционный откат (Rollback)**: варийное удаление созданного черновика (movetobinpage), если сборка оборвалась на середине.
* **JSON Sanitizer**: езопасная обработка спецсимволов ( , &quot;, &amp;, тире) перед отправкой в параметры блоков Tilda.

###  Точечное редактирование (	ilda_update_page_section)
* гновенное обновление конкретной секции (например, изменение цен или отзывов) за **~2.9 секунды** с автопоиском блока по якорю и автоматической перепубликацией.

##  авигация и якоря

вижок поддерживает сквозную бесшовную навигацию по 6 ключевым разделам:
* #features  реимущества / аправления
* #metrics  ифры и факты
* #pricing  Тарифная сетка
* #reviews  тзывы клиентов
* #faq  астые вопросы
* #form  орма захвата лидов
